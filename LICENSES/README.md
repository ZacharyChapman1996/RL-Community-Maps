# Map permissions and attribution

Each map must have documented redistribution permission before its file is published in a release.

For every map, retain:

- Original creator or rights holder
- Original source page or download location
- Permission basis (license, explicit permission, or other documented authorization)
- Attribution and any redistribution conditions
- Release tag, asset filename, byte size, and SHA-256 checksum

Do not assume that a map is redistributable merely because it is publicly downloadable. Copyright and other rights remain with the original creators or rights holders.
